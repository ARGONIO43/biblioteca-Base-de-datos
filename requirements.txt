## Dependencias del proyecto

# Este proyecto solo usa librerías estándar de Python
# No requiere instalación de paquetes externos
# Compatible con Python 3.7+

# Librerías estándar utilizadas:

# - logging (registros de operaciones)
# - datetime (manejo de fechas y horas)

# Opcional para desarrollo:
# pytest>=7.0  # Para testing
# black>=22.0  # Formateo de código
# flake8>=4.0  # Linting
